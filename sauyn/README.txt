САУЫН SHOW — MVP
1. В существующем Supabase SQL Editor создайте новый запрос, вставьте database.sql и Run. Создаются только sy_* таблицы и функции и отдельная cron-задача. CircleShow не меняется.
2. В config.js замените YOUR_PUBLISHABLE_KEY на тот же публичный ключ, что использует CircleShow. Не копируйте secret/service_role ключ.
3. Загрузите папку sauyn в корень Medetshow. Публикуйте только index.html, join.html, config.js; SQL и README нужны для настройки, их можно оставить локально.
4. Откройте https://www.medetshowss.shop/sauyn/index.html после публикации. Войдите существующим аккаунтом ведущего. F2 → Новая игра. Четыре гостя сканируют QR, вводят имя, разрешают датчики. F2 → Старт. 3 секунды отсчёта, 60 секунд игры. После окончания до 2,5 секунды на доставку последних результатов. Результаты удаляются при новой игре, завершении или по cron через 24 часа.
5. Проверьте на iOS и Android, датчики, запасной режим кнопки, 4 одновременных игрока, восстановление сети, полноэкранный режим. Векторные персонажи нарисованы SVG, анимация CSS. Литры виртуальные; 0,05 л за движение. Не трясите телефон резко. Сервер ограничивает максимально допустимый темп, но не может удостоверить физическое движение на клиенте; это развлекательная игра, не античит для денежных соревнований. Результаты доступны по секретному идентификатору комнаты; не публикуйте QR вне мероприятия. При перезагрузке страницы игрока доработка восстановления участия может понадобиться: место сохраняется на сервере, но после старта повторное подключение через интерфейс не предусмотрено.
