САУЫН SHOW v6 — полный комплект восстановления
1. Распакуйте архив. Внутри папка sauyn.
2. В sauyn/config.js замените только YOUR_PUBLISHABLE_KEY на действующий публичный ключ из Кружочек SHOW. Адрес Supabase уже указан. Секретные ключи не используйте.
3. В существующем Supabase, если обновление старта ещё не установлено, SQL Editor → Create a new snippet → вставьте update-start.sql → Run один раз. Если база новой игры была удалена, вместо этого выполните database.sql (полная схема уже включает старт с 2 игроков). Не удаляйте старые таблицы. Не выполняйте старый SQL из v1.
4. Загрузите папку sauyn целиком в корень Medetshow через Add file → Upload files → Commit changes. Проверьте, что путь sauyn/index.html, без лишней внешней папки. SQL и README можно оставить локально.
5. После публикации откройте https://www.medetshowss.shop/sauyn/index.html и обновите Ctrl+F5. Войдите прежним аккаунтом ведущего. F2 → Новая игра. Карточки появляются только при подключении игроков, старт доступен с 2–4 игроками. Раунд 60 секунд. Рисовка встроена в HTML, assets не нужны.
6. Проверьте подключение двух телефонов и запуск, затем 3–4 игроков, датчики iOS/Android, финал и очистку. Если старая комната сохранилась в базе, она может восстановиться при входе; Новая игра удалит её после подтверждения. Сетевая проверка на реальном Supabase не выполнена.
